# 🥒 Rick and Morty

A web application for browsing characters from the Rick and Morty universe. Includes character search, detailed character pages, and the ability to save selected cards in CSV format.

## 🖼️ [Preview](https://olydbd-rs-react-app.netlify.app/)

## ⚙️ Tech Stack

- React
- TypeScript
- React Router
- Redux Toolkit
- RTK Query
- Tailwind CSS

## ✨ Features

- Fetching character data from the public API
- Displaying character cards with images and details
- Search by character name
- Detailed character pages
- Add characters to a saved list
- Export selected characters to CSV
- Clear saved list
- Fully responsive design

## 🛠️ Installation and Setup

1. Clone the repository

   ```bash
   git clone https://github.com/olydbd/rs-react-app.git
   ```

2. Navigate to the project folder

   ```bash
   cd rs-react-app
   ```

3. Install dependencies

   ```bash
   npm install
   ```

4. Start the development server

   ```bash
   npm run dev
   ```

## 🌐 API

Data is fetched from the open [Rick and Morty API](https://rickandmortyapi.com/)
